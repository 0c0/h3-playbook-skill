# H3 能力边界（官方口径）

## 输出

| 项 | 规格 |
|---|---|
| 时长 | 4–15 秒 |
| 帧率 | 24 FPS（固定） |
| 声音 | **所有结果全部带声音，原生双声道** —— 没有"静音输出"开关，只能靠提示词压 |
| 分辨率 | **768p 模式**（已开放）：16:9~9:16 之间 → 短边 768；区间外 → 总面积 ≈ 1M px（21:9 = 1536×672）<br>**1440p 模式**（官方推荐）：16:9~9:16 之间 → 短边 1440；区间外 → 总面积 ≈ 3.7M px（21:9 = 2976×1248）<br>768p 结果可升级至 1440p |
| 宽高比 | 首/尾帧模式 → **遵循输入图片的原始长宽比**；文生 / 全能参考 → 指定 21:9 / 16:9 / 4:3 / 1:1 / 3:4 / 9:16，或选自动由 H3 判断 |

## 输入条件

### 首/尾帧入口（FL2VA）

- 图片：**0 / 1 / 2 张**；宽高范围 [256, 5760]；**宽高比必须在 5:2 ~ 2:5 之间**
- 无图片 = 文生视频模式

### 全能参考入口（Ref2VA）

| 类型 | 上限 | 约束 |
|---|---|---|
| 图片 | ≤ 9 张 | 宽高 [256, 5760] |
| 视频 | ≤ 3 段 | 单段 2–15 秒、**总长 ≤ 15 秒**、宽高 [256, 5760]、宽高比 5:2~2:5 |
| 音频 | ≤ 3 段 | **必须配图片或视频输入，不能单独输入**；单段 2–15 秒、总长 ≤ 15 秒 |
| 混合 | **总上限 12 个文件** | 图+视频+音频加一起 |

⚠️ 9 图 + 3 视频 + 3 音频 = 15 > 12，是**不允许**的组合。凑满 12 的合法组合例如：
9 图 + 3 视频 / 6 图 + 3 视频 + 3 音频 / 9 图 + 3 音频。

### 格式与大小

- 视频：H.264/AVC、H.265/HEVC；视频内音频：AAC、MP3
- 图片：JPG、JPEG、PNG、WEBP、HEIC、HEIF
- 音频：WAV、MP3
- 单文件上限：视频 50MB / 图片 30MB / 音频 15MB（**限制只在单个素材上，加起来不限**）
- API 请求体 64MB（推荐用 url 传素材）

## 提示词

- **上限 7000 字符**（中英都算）

## 语言

- 提示词输入/输出支持多语言
- **TTS 精准覆盖 11 种语言**：中、英、日、韩、法、德、西等
- 可衍生拓展 40+ 语言：阿拉伯语、泰语、印尼语、印地语等
- 适合海外品牌传播、多语种广告、跨语言短片、本地化产品介绍

## 能做什么（官方三大能力）

1. **原生多模态理解与生成** —— 文字/图片/音频/视频统一上下文，理解人物、动作、声音、情绪、镜头、风格与表达意图。
2. **多模态精准编辑与控制** —— 对人物、物体、场景、声音、节奏多维度编辑；可在已有内容上持续修改迭代。
3. **商用级多场景内容生成** —— 影视、广告、品牌、电商、游戏；兼顾文字字幕、品牌信息、创意特效、产品展示、UI/UX 动态演示。

### 编辑类能力清单（Ref2VA）

- 角色与物体编辑：替换 / 删除 / 增加人物与物体
- 场景与视觉效果编辑：换背景、调光影氛围、增删视觉特效
- 声音、台词与音色修改：替台词、迁移音色、调人声
- 高精度指令遵循：局部修改的同时保持未编辑内容相对稳定

### 参考能锁什么

多素材联合参考 / 角色形象 / 动作 / 运镜 / 构图 / 节奏剪辑 / 音色克隆迁移 / 风格 / 氛围
