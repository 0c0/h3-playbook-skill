# 参考素材用途标签（官方枚举）

上传了素材，就必须说清它**是干什么用的**。官方给的用途标签就这些，挑一个写，不要自己造。

| 标签 | 锁定什么 |
|---|---|
| 人物参考 | 锁脸 / 形象 |
| 物体参考 | 锁物体 |
| 场景参考 | 锁场景 |
| 关键帧 | 锁帧（有首帧/尾帧需求要明确写出） |
| 音色参考 | 锁音色 |
| 故事版 | 根据故事版分镜生成镜头内容 |
| 风格参考 | 按图片风格生成类似风格的内容 |
| 构图参考 | 按图中物体构图生成对应构图 |
| 动作参考 | 锁动作 |
| 运镜参考 | 锁运镜 |
| 视频编辑 | 对视频某个内容做增删改 |
| 音频复用 | 生成视频的音频直接复用参考音频素材 |
| 音频部分复用 | 某个声音轨道 / 某个时间段部分复用参考音频 |

其他要求也可按需写明 —— 标签是**起点不是牢笼**。

## 写法示例

```
@图片1 提供了 [角色名] 的形象，@视频2 提供了动作参考。
```

多个角色要能指代清楚（"穿红裙的女子"vs"戴眼镜的男子"），别只写"她"。

## 音频复刻的额外要求

音频复刻 / 部分复刻时，**如果对人声对白内容或唱歌歌词内容有较高保持要求，强烈建议把歌词/台词原文补进去**：

```
@音频1 作为目标视频的音频复刻素材，具体歌词是："ABCDEFGHIJKLMN"。
```

不补原文，模型只能猜，多半猜错。

## 素材里的特征要显式写出来

"如果素材中有非常想要保持的特征，建议明确写出来，这样可以让一致性更好。"

例：不要只写 `@图片1 是人物参考`，要写
`@图片1 是人物参考，锁定：白金长发、窄黑复古墨镜、黑色高光漆皮风衣`。

## 官方 goodcase 里的典型多素材分工

品牌/时尚类常见这套分工，可直接套：
