# 三段式骨架（照抄改）

## 万能骨架

```
【参考素材说明】
@图片1：人物参考（锁定：脸型、发型、服装、气质……）
@图片2：场景/风格参考（锁定：色调、材质、光线……）
@视频1：动作参考（锁定：……动作轨迹）
@音频1：情绪/节奏参考 或 音频复用（歌词原文："……"）
（无素材时本段整段删除）

【核心创意】
<时长>秒、<16:9/9:16/……>。<主体>在<地点>做<事件>，
<题材/风格>，<特殊运镜/切镜风格>。

【画面过程描述】
Shot 1 — <景别> / <空间>
- 场景：<……，参考 @图片2>
- 景别：<极近特写 / 中近景 / 全景 / 手部特写 ……>
- 人物：<谁，做什么，表情>
- 运镜：<推/拉/摇/移/手持/固定>
- 台词：<角色名>说："<原文>"
- 音效：<……>
- 硬切

Shot 2 — …
…

Final — <收尾镜头>

【整体要求补充】
▍影像风格（贯穿全片）：<颗粒、抖动、色偏、转场形式……>
▍禁止项（贯穿全片）：<不要字幕 / 不要 3D / 不要新增人物 / 不要柔和溶解……>
▍环境音（贯穿全片）：<只允许哪些声音>
非叙事性音乐：N/A   ← 或写明要什么 BGM
```

## 每个 shot 的 6 项（缺一项就补）

**景别 + 内容 + shot 内运镜 + 动作 + 台词 + 音效**

景别清单（挑一个明说，别让模型猜）：
极近特写 / 面部特写 / 肩颈特写 / 手部特写 / 中近景 / 半身近景 / 双人中景 / 全景 / 大全景。

## 三种模式的骨架差异

### 纯文生（T2VA）

第一段**整段没有**。第二段信息量要加倍 —— 主体外观、场景细节、动作全写。
分层写法兜底：

```
【核心创意】<题材/风格>。<主体（含外观）>在<地点（含环境细节）><事件>。
【画面过程描述】
Shot 1 大全景：<交代空间>
Shot 2 中景：<承载动作>
Shot 3 特写：<强调细节>
```

### 图生（首/尾帧，FL2VA）

```
@图片1 是首帧参考图：<画面内容>。
@图片2 是尾帧参考图：<画面内容>。
让她从<起势>到<收势>，自然衔接，不要切镜。
```
⚠️ 首+尾帧模式 H3 **不会自动加切镜** —— 只补两帧之间的动作/光影/声音。
要快切就别用这个模式，用文生或全能参考。

只传 1 张时**必须说清是首帧还是尾帧**，不说清模型会随机理解。

### 全能参考（Ref2VA）

```
@图片1 是人物参考（锁这位女子的脸），
@视频1 是动作参考（用里面的舞剑动作），
@音频1 是情绪参考（古风配乐）。
让这位女子在樱花庭院里按视频里的动作舞剑。
```

## 官方完整示例（可直接对照格式）

```
【参考素材说明】@图片1 提供了 xx 角色的形象，@视频2 提供了动作参考。

【核心创意】一位穿汉服的年轻女子（@图片1）在樱花纷飞的庭院里舞剑，
古典国风，电影质感，一镜到底。

【画面过程描述】
0-3 秒：全景，女子（@图片1）从画面左侧缓步走入樱花庭院（@图片2），背景虚化，没有对白，只有脚步声。
3-8 秒：切镜到女子（@图片1）的中景，她拔出长剑（@图片3），缓缓起势，樱花瓣从树上飘落。镜头推进。
8-12 秒：切镜到特写，剑光一闪，慢动作，樱花被剑气激得四散。
非叙事性音乐：N/A
```
